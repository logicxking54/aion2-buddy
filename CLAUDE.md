## What this is

**Aion 2 Buddy** — a Wails v2 desktop app (Go backend + Vue 3/TypeScript frontend) that helps with the MMO *Aion 2*. Go module: `aion2tmp`. Windows-only.

Menus (each is a "project" under `frontend/src/projects/`, registered in `registry.ts`):
- **Ping Maker** — the core feature. Intercepts the game's TCP packets with WinDivert and rewrites the combat-speed field of configured skills so casts play faster. **Requires admin** (WinDivert kernel driver).
- **Mod** — reversible game tweaks (remove intro video, TCP latency tuning, NIC tuning). Writes game files / system settings with backups for rollback.
- **Packet Inspector** (dev-only) — dump captured packets (hex + opcodes), record full sessions to JSONL, decode casts.
- **Settings**.

## Build / run / test

Toolchain lives at non-default paths — prepend to PATH:
- Go: `/d/Program Files/Go/bin` · Wails CLI: `~/go/bin/wails` · NSIS (installer): `/d/Program Files (x86)/NSIS`

```bash
export PATH="/d/Program Files/Go/bin:/d/Users/Singh/go/bin:/d/Program Files (x86)/NSIS:$PATH"

# Go (capture engine lives in internal/capture)
go build ./...
go test ./internal/capture/
gofmt -w internal/capture/*.go *.go
go vet ./...

# Frontend (run from frontend/)
cd frontend && npx vue-tsc --noEmit     # typecheck — do this after any .ts/.vue change

# Full app + Windows installer (regenerates Wails bindings + bundles the frontend)
wails build -nsis -platform windows/amd64
#   -> build/bin/aion2-buddy.exe  and  build/bin/aion2-buddy-amd64-installer.exe
#   (NSIS must be on PATH; don't use -clean — it wipes the manually-renamed build/bin artifacts)
```

Most `internal/capture` files are `//go:build windows`. Benchmarks: `go test ./internal/capture/ -run '^$' -bench . -benchmem` (some take `SESSION=<jsonl>` to replay a real recording).

## Architecture

- **Go backend** exposes methods to the frontend via Wails bindings in root `*_bindings.go` (`Capture`, `Mod`) and `app.go` (`App`). They're thin façades over `internal/capture` (the engine) and `internal/gamemod`. Generated TS bindings land in `frontend/wailsjs/` (auto-regenerated by `wails dev`/`build` — don't hand-edit).
- **Frontend** (`frontend/src`): `App.vue` + `captureController.ts` (single owner of capture state, wires engine events) + per-menu components. Shared persisted settings in `config.ts` → `%APPDATA%\aion2-buddy\skills-config.json`.
- **Capture engine** (`internal/capture/engine.go`, `protocol.go`): WinDivert pulls packets out of the stack in a single-threaded loop `recv → processPacket → reinject`. It is **in-line** — time spent in `processPacket` is added directly to packet latency (measured ~3–6.5µs/packet, negligible vs network ping).

## Packet protocol — the critical domain knowledge

- Traffic is **asymmetric**: **server→client game data is PLAINTEXT** (varint-framed) — that's why we can read/edit casts. **Client→server (outbound) is ENCRYPTED** (plus TLS `17 03 03` on a side channel) — its content is unreadable; don't try to decode it. Only outbound size+timing is usable (e.g. a `len=28` packet ~ping-ms before a cast = the cast request).
- A cast packet: `38 <caster varint> <flag 00|01> <skill_id u32 LE> <tick> <pkt_type> <entity varint> <4× float32 position> <attack_speed> <marker> <trailing record>`. `pkt_type` 0x02 = ACT cast (carries position+speed, editable); 0x00 = self-buff; 0x03 effect. The attack_speed is a varint OR a float32 holding `value/10000`.
- **Party packets are LZ4-block-compressed**: `<varint len> ff ff <u32 origLen> <LZ4 block>`. The engine decompresses with provenance (`lz4DecompressTrace`), finds the speed in the clean stream (strict id-anchored parser), and writes the new bytes back into the exact block **literals** — length-preserving. Casts whose speed is a back-reference *match* are unreachable (rare).
- **Edits MUST be same-length** to preserve TCP seq numbers — never change a packet's length (the whole compressed-edit design exists to avoid re-segmentation / reconnects).
- **Caster filter** (engine-level `casterFilter`): auto-detected — the first ACT cast of one of *your configured (edit-list) skills* locks its caster; thereafter only that caster's casts are edited. Runtime-only (caster id changes every session; never persisted). Known gap: a same-class teammate casting your exact skill can flip it (deferred).

## Conventions

- **Commits/tags/push: only when the user explicitly asks.** End commit messages with `Co-Authored-By: Claude Opus 4.8 <noreply@anthropic.com>`. Work happens on `develop`.
- **Release flow**: bump `wails.json` `info.productVersion` (drives both the in-app `__APP_VERSION__` badge and the installer metadata) → add an entry at the TOP of `releases` in `frontend/src/components/ChangelogModal.vue` (both `en` + `th`) → `wails build -nsis` → commit `Release vX.Y.Z` → `git tag -a vX.Y.Z`.
- **i18n**: every UI string goes in both `frontend/src/i18n/en.ts` and `th.ts`. Menu labels under `menus.<id>`.
- Shell is Git Bash here; the app is PowerShell-friendly. Watch the `LF→CRLF` git warnings — harmless.
- Don't commit `build/bin/*.exe` or `frontend/dist` (gitignored).
